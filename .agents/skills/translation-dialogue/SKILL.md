# 人物の口調設計と会話翻訳

このリポジトリの翻訳を作成・改訂・レビューする際に使用する。本文の保存形式はルートの `TRANSLATION_YAML_SPECIFICATION.md` に従う。

## 必須の作業順序

**ルート README.md → この SKILL.md → 各作品フォルダの README.md → 翻訳作業** の順を守る。

1. ルート README で対象作品・対象範囲を確認する。このスキルを読んでから、対象YAMLを置く作品フォルダの README を開く。
2. 作品 README がない場合、翻訳より先に原文を通読し、実際に登場する人物・発話集団を洗い出して作成する。既存の場合も、対象回の人物・場面を網羅しているか確認する。
3. 人物・発話集団ごとに、原文に根拠のある性格、口調、一人称、呼びかけ、語尾、相手や感情による変化を考える。根拠の回・対訳IDを添え、口調の例を**3個**書く。例は創作の口調見本だと明示し、原典の引用や本文追加として扱わない。発言のない人物に口癖を創作しない。
4. 作品 README の口調ガイドを参考に翻訳・改訂する。未登場人物や後の回の性格を先回りして適用せず、対象回の原文と人物関係を優先する。同じ人物でも、師への敬語・仲間への親しみ・敵への挑発を使い分ける。
5. 会話の全発言を原文と照合する。各セリフの前に発言者を付け、口調の一貫性と意味・敬意・感情の保持を確認する。既存訳が適切なら、修正件数のためだけに書き換えない。
6. 問題・修正点を記録し、作品固有の人物判断は作品 README、他作品にも起こる手順上の問題はこのスキルへ反映する。変更した手順でもう一度対象訳を確認する。
7. YAML仕様に従い内容ハッシュ・目録・参照・レビュー状態を整合させ、差分とテストを確認し、依頼対象の変更だけをコミット・プッシュする。変更対象、保持した原文・ID、検証結果、未確認範囲を報告する。

## 必須ルール

- 会話のラリー（複数の発言が続くやり取り）では、**各セリフの前に発言者名を付ける**。最初の発言だけでなく、返答・問い返し・短い相づちにも毎回付ける。同じ人物の発言が続いても省略しない。
- 基本形は `悟空「……」`、`祖師「……」` のように、発言者を鉤括弧の直前に置く。既に `悟空は答えた。「……」` のように直前で明記されている場合は、その形を維持し、名前を二重に付けない。セリフの後ろだけの発言者表記では、この要件を満たさない。
- 原文の発話動詞、代名詞、前後の文脈に照らして話者を確認する。登場人物の名称・呼称は作品内で統一する。原文が集団の発言なら `猿たち「……」` のように集団を示す。
- 話者を確定できない場合、人物名を推測して補わない。`話者不明「……」` と明示し、既存の訳注・確認事項の仕組みに不確実性と確認対象を記録する。
- 発言者名は日本語訳に付ける。原文 `source_text` を書き換えない。地の文、詩、引用中の語句を、鉤括弧があるというだけで登場人物の発言に変えない。入れ子の引用は実際の発話と区別する。
- セリフの内容・順序・意味、地の文、対訳単位の固定IDを保つ。発言者表記のために内容を省略・要約したり、未依頼の章を翻訳したりしない。

## 確認例

不適切な例（発言者を読者に推測させる）：

「何を学びたい？」
「長生きする術を学びたい。」
「それなら教えよう。」

適切な例（例示用の会話であり、原典の引用ではない）：

祖師「何を学びたい？」
悟空「長生きする術を学びたい。」
祖師「それなら教えよう。」

## レビューと検証

1. 会話をやり取りの開始から終了まで読み、各発言の直前に正しい発言者があるか原文と照合する。話者交代だけでなく、短い返答・同一話者の連続発言・集団発言も確認する。
2. 表記漏れ、誤帰属、呼称の揺れ、名前の二重付与、原文の変更がないことを差分で確認する。文字列検索だけで話者の正しさを保証したことにしない。
3. 訳文を変更した場合は、既存仕様に従って参照文字範囲・レビュー状態・内容ハッシュ・目録を更新し、既存のYAML検証とテストを実行する。実施していない独立校訂を完了扱いにしない。

## 口調改訂で繰り返さないための注意

- 人物を「傲慢」「無礼」等の一語に固定しない。相手への礼、場面の恐れや感謝まで乱暴な語尾へ変えない。
- 別名・命名前後の名前を同一人物として管理する。名づけ以前の発言者名を、後で得る名前に一律変更しない。
- 一人称・呼称はセリフの話者と相手を確定してから修正する。ファイル全体への機械的な置換は、他人の一人称や引用中の声を壊すため避ける。
- 集団の返答や伝聞・入れ子の引用を一人の発言へ変えない。逆に「私たち／我等」と言っていても、発話動詞の主語が一人なら集団ラベルにしない。「皆に混じって答えた」人物の主語と「皆が答えた」を区別し、前後の文法を確認する。
- 「悟空は答えた。孫悟空『……』」のような導入とラベルの重複は整理するが、笑う・怒る・拝む等の動作や感情は落とさない。鉤括弧の前が人物名ならよいという機械判定だけで済ませない。
- 方言・奇抜な口癖・罵倒を人物らしさのためだけに追加しない。詩、碑文、経典引用、語句の括弧を通常の会話と混同しない。
- 本文の語調だけの改訂でも、既存の注・文字範囲・レビュー用ハッシュが古くなり得る。原文・固定ID・順序の不変を別に確認し、レビュー状態を実際以上に引き上げない。

- 話者ラベルの整形では「兄弟子たち／弟子たち」「さらわれた猿たち／猿たち」のような包含関係に注意する。短い名前への部分一致でラベルを分断しない。整形後の実際の改行と全話者名を見直す。

- 口調を整えるときも、誓い・義務・可能性の強さを変えない。「恩を忘れない」を「必ず恩返しする」に、「必ず」を「かもしれない」に置き換えない。原文にない動機や結果を台詞へ補わない。

## 古典の語義・資料照合

- 慣用句・挨拶・諺は、現代の字面だけで訳さず、その場面の話者・相手・行為と辞書の語義を照合する。同じ挨拶が奏状等に再引用される場合は、引用先でも意味をそろえる。
- 底本の難字・異体字・人物名を、一般に知られる表記や別版の名前へ無断で置き換えない。字義が確定できなければ原字を保持し、訳注や既知の留保として明示する。未確認箇所を省略して全文訳と呼ばない。
- 回題の誇張、人物の主張、語り手の事実説明を区別する。「多くの者」を「全員」に、夢の場面を「実効がなかった」に変えるなど、範囲・因果を補わない。単位の斤・丈等も時代差を無視して確定的な現代単位へ換算しない。
- 新規の回を訳すときは固定版の出典と本文スナップショットを確保し、回題・全散文・挿入詩・書簡や奏状・結語を対訳単位と照合する。本文の区切りや空白の正規化を行った場合は記録し、欠落を機械的にも確認する。

- 移動・侵入・攻撃の動詞を訳すときは、原文が述べる動作と、その結果として起きた破壊を区別する。「押し入る」を、記述のない「門を突き破る」にしない。反語を含む諺は、日本語でも反語だと伝わる形にする。

- 官職・儀礼・武器・固有名の列挙は、その回の本文と語義を優先する。任官を免官、作揖を平伏に変えたり、後世に有名な武器名・姿へ置き換えたりしない。前の回と異なる表記は、無断統一せず相違を記録する。
- 底本の引用符が欠けているときは原文欄を補訂しない。訳文では発話の主語・文脈に基づき引用の範囲を示し、その判断と留保を記録する。人物が伝える発言を、そのまま語り手が確認した事実へ変えない。
