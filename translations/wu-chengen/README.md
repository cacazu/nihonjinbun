# 西遊記：翻訳と人物の口調ガイド

## 適用範囲と読み順

ルート [README](../../README.md) → [翻訳スキル](../../.agents/skills/translation-dialogue/SKILL.md) → この README → 対象回の原文・翻訳、の順に読む。

対象は第一回〜第七十五回。以下は同梱の中国語原文から読み取れる人物像に基づく翻訳上の設計であり、作品全体の性格を断定しない。後の回で新人物や新たな関係が出たら、原文を確認して更新する。人物の名・口調・正体は、各場面で明らかになった範囲を使い、後の情報を先回りさせない。

**以下の例文は口調を示すための創作例であり、原典の引用でも本文へ追加するセリフでもない。** 各人物・発話集団に3例ずつ示す。場面ごとの敬意・感情は原文を優先する。

## 人物別の特徴と例文

### 孫悟空（石猿・美猴王と同一人物）

- 自信家、負けず嫌い、率直でせっかち。敵には傲慢で無礼な挑発もする。一方、求道時は教えを乞う敬意があり、仲間には保護者として振る舞う。「傲慢」だけで全場面を乱暴に訳さない。
- 仲間・敵・独り言では一人称「俺」、師や教えを求める相手、兄弟子に親しみのある敬語で話す場面では「私」。原文の「弟子」は必要な場面で「弟子の私」等にする。「老孫」は誇示する自称なので、無説明の漢語を乱用せず「この俺」などで威勢を表す。「わし」への根拠のない揺れは避ける。
- 師への呼びかけは「お師匠さま」。兄弟子へは親しみのある敬語。地の文と発言者は下の場面別呼称表に従い、石猿・美猴王・孫悟空・弼馬温・斉天大聖を使い分ける。別人格に分けない。
- 根拠：第一回 xy-ch01-012・019・038・045・048・049、第二回 xy-ch02-005・019・022・025・029・036・038。

1. 仲間へ：石猿「俺が先に行く。みんな、ついてこい！」
2. 師へ：孫悟空「お師匠さま、どうか私にもその術をお授けください。」
3. 敵へ：孫悟空「大口をたたくな。この俺の拳を受けてみろ！」

### 須菩提祖師

- 威厳があり、簡潔な問いで相手を試す。教えるときは落ち着いて説明し、叱るときは鋭い命令・断言になる。冗談やたとえ話もするため、常時怒鳴る人物にしない。
- 一人称「私」、相手は「お前」または「悟空」。語尾は「〜だ」「〜せよ」「〜なさい」「〜ならぬ」を場面で使い分ける。現代の学校の先生のような呼称・軽口は避ける。
- 根拠：第一回 xy-ch01-048・049、第二回 xy-ch02-005〜011・018〜020・025・026。

1. 問い：須菩提祖師「悟空、お前は何を学びたいのだ。」
2. 教え：須菩提祖師「心を静めよ。肝心なところをよく聞くのだ。」
3. 叱責：須菩提祖師「人前で術を見せびらかすために学んだのか。」

### 花果山の猿たち（さらわれた猿たちを含む）

- 仲間同士ではにぎやかで素朴、好奇心旺盛。王への喜び・不安・訴えは素直で切実。王になる前と後で距離が変わる。
- 仲間同士は「俺たち」、大王への改まった発言は「私たち」「〜です」。呼びかけは「大王」。集団の発言を特定の一匹へ勝手に割り当てない。
- 根拠：第一回 xy-ch01-010・012・017・019・023・024、第二回 xy-ch02-029・037・038。

1. 仲間同士：猿たち「俺たちで水の出どころを探そうじゃないか！」
2. 歓迎：猿たち「大王、お帰りをずっと待っておりました！」
3. 訴え：さらわれた猿たち「大王、私たちには帰り道が分からないのです。」

### 長腕の猿

- 見識があり、王の悩みを受け止めて助言する。穏やかな説明調と敬意を持たせ、現代的な解説者や滑稽な老人にしない。
- 呼びかけは「大王」、語尾は「〜です」「〜おります」。原文の通背猿を、後の回の同名・同種の存在と憶測で同定しない。
- 根拠：第一回 xy-ch01-024。

1. 長腕の猿「大王、それは道を求める心が芽生えたということです。」
2. 長腕の猿「死の支配を離れた方々が、この世にはおります。」
3. 長腕の猿「その方々は、仙人の山や古い洞窟に住んでおられます。」

### 木こり

- 誠実で控えめ、暮らしと母の世話を優先する実直な人物。初めは丁寧だが、事情を理解しない誘いには苛立ち、率直に断る。
- 一人称「私」。通常は「あなた」「〜です」、苛立つ場面は「あんた」「〜だろう」。歌は詩として扱い、会話の口語へ無理にそろえない。
- 根拠：第一回 xy-ch01-035・038・039。

1. 木こり「私はただの木こりです。仙人などではありません。」
2. 木こり「母を養わなければなりませんから、山を離れられないのです。」
3. 木こり「あんた、さっきの話を聞いていたのか。私が出かけたら、誰が母を養うんだ。」

### 童子

- 師の言葉を伝える落ち着いた案内役。門を守る立場のきびきびした問いと、迎え入れる口調を区別する。幼い見た目だけで赤ちゃん言葉にしない。
- 一人称「私」、相手は「お前」。師は「お師匠さま」、案内は「〜おいで」。引用する師の言葉は師の口調を保つ。
- 根拠：第一回 xy-ch01-045。

1. 童子「誰だ。門の前で騒いでいるのは。」
2. 童子「お師匠さまがお前を迎えるようにとおっしゃった。」
3. 童子「では、私についておいで。」

### 兄弟子たち・弟子たち

- 師への敬意と、悟空への親しみ・好奇心・からかいが共存する集団。悟空の見せ場でははしゃぎ、叱責されると改まる。
- 同門同士は「〜だな」「〜見せてくれ」、師には「お師匠さま」「〜ございます／〜ました」。原文が一同の発言ならラベルも集団とし、悟空一人の発言にしない。
- 根拠：第二回 xy-ch02-010・020・022・024。

1. 兄弟子たち「悟空、その術はもう覚えたのか。ひとつ見せてくれ。」
2. 弟子たち「見事な猿だ！　本当に木に変わったぞ。」
3. 弟子たち「お師匠さま、皆で騒いでしまいました。どうかお許しください。」

### 玉帝

- 上位者として落ち着き、短く事態を判断する。第一回の発言だけから残酷・滑稽といった後世のイメージを付加しない。
- 「〜であろう」「〜に及ばぬ」のような威厳ある断定。不要な「朕」や古語を補って誇張しない。
- 根拠：第一回 xy-ch01-006。

1. 玉帝「下界の様子を確かめてまいれ。」
2. 玉帝「天地の精気から生まれたものであろう。」
3. 玉帝「その程度のことなら、怪しむには及ばぬ。」

### 千里眼と順風耳

- 玉帝に仕える報告者。事実を順序立てて述べ、敬語は丁寧で簡潔にする。原文でまとめられた報告を二人の掛け合いに創作しない。
- 合同のラベル「千里眼と順風耳」、語尾「〜ございます」「〜いたしました」。
- 根拠：第一回 xy-ch01-006。

1. 千里眼と順風耳「仰せに従い、下界を調べてまいりました。」
2. 千里眼と順風耳「花果山の石から、一匹の猿が生まれたのでございます。」
3. 千里眼と順風耳「光はすでに弱まりつつあります。」

### 混世魔王

- 尊大で粗暴、相手の体格や武器を見て侮る。自分の強さと面目を誇る口調。「公平な勝負」の発言を善良さに読み替えない。
- 一人称「わし」、相手は「お前」。嘲笑や命令は「〜というのか」「〜してやろう」「〜持ってこい」。悟空の「俺」と区別する。
- 根拠：第二回 xy-ch02-033・034・036。

1. 混世魔王「どいつがこのわしに挑もうというのだ。」
2. 混世魔王「そんな小さな体で、よくも大口をたたけるものだ。」
3. 混世魔王「刀を置いて、拳で相手をしてやろう。」

### 小妖怪

- 主に仕える下役。異変には慌て、報告には相手の外見・要求を具体的に述べる。語尾を漫画的に崩さない。
- 呼びかけは「大王」、語尾は「〜です」「〜おります」。人数が曖昧なら名前や役職を創作しない。
- 根拠：第二回 xy-ch02-033。

1. 小妖怪「大王、大変です！　外に猿が来ております。」
2. 小妖怪「水簾洞の主人だと名乗っております。」
3. 小妖怪「武器は持たず、素手で叫んでいます。」

### 四匹の老猿（のちの四健将）

- 経験をもとに武器の入手先や竜宮への道を示す助言役。二匹の赤尻馬猴と二匹の通背猿猴で、第一回の長腕の猿との同一性は断定しない。
- 大王への敬語で「私たち」「〜ございます／〜です」。四匹の合同発言は「四匹の老猿」、任命後に猿たちと一緒に呼ぶ箇所は「四健将と猿たち」とする。
- 根拠：第三回 xy-ch03-002・008・015・020。

1. 四匹の老猿「大王、武器をお求めでしたら、心当たりがございます。」
2. 四匹の老猿「あちらの国で買うか、作らせるのがよろしいでしょう。」
3. 四匹の老猿「それほどの神通力がおありなら、海にもお入りになれますね。」

### 海を巡る夜叉

- 海の見張り役として相手の身元を確かめ、王には急いで報告する。問いは職務上の丁寧さを持ち、悟空の尊大さにつられて粗暴にしない。
- 相手に「どちらの方」、王に「大王」「〜と申しております」。原文の問答と報告を別々の発言として保持する。
- 根拠：第三回 xy-ch03-009。

1. 夜叉「水を分けて来られるのは、どちらの方ですか。」
2. 夜叉「お名前を伺えれば、王にお取り次ぎいたします。」
3. 夜叉「大王、お隣に住む方だという仙人が、お越しになります。」

### 東海竜王・敖広

- 初めは礼を尽くす主人役だが、悟空の力におびえ、穏便に帰らせようとする。弟たちには事情を説明し、玉帝への奏状では臣下として被害を訴える。
- 悟空には「上仙」「〜ございます／〜ください」、兄弟には「お前たち」「〜なのだ」。一人称は通常「私」、奏状では「臣、敖広」。
- 根拠：第三回 xy-ch03-009〜013・023。

1. 敖広「上仙、どうぞお入りください。」
2. 敖広「それ以上に重い武器は、もうございません。」
3. 敖広「お前たちのところに、譲れる鎧はないだろうか。」

### 竜王の妃と竜女

- 悟空の力と宝の光に気づく観察者。妃は使い道よりも早く帰ってもらうことを重んじ、現実的に助言する。竜女だけの発言はないため単独の口癖を作らない。
- 合同発言は「妃と竜女」、続く妃だけの発言は「妃」。王には「大王」「〜ではありませんか／〜なさいませ」。
- 根拠：第三回 xy-ch03-010。

1. 妃と竜女「大王、あの方は並の仙人ではないようです。」
2. 妃と竜女「宝が光っているのは、持ち主に出会うしるしではありませんか。」
3. 妃「どう使うかはあの方に任せて、お帰りいただけばよいのです。」

### 南海竜王・敖欽

- 兄の被害を聞いて怒り、まず兵を出すことを提案する。制止された後は装束を出す。怒りを常時の罵倒や粗暴な口癖へ拡大しない。
- 一人称「私たち」、長兄を「兄上」。兄弟間では「〜ではないか」「〜がある」。
- 根拠：第三回 xy-ch03-013。

1. 敖欽「兄上、何があって鐘と太鼓を鳴らしたのですか。」
2. 敖欽「私たちで兵を集め、捕らえればよいではありませんか。」
3. 敖欽「私のところには、差し出せる冠があります。」

### 西海竜王・敖閏

- 直接対決を避け、天界へ訴える方策を提案する。状況を見て落ち着いて制する口調。後の回の家族関係や性格は持ち込まない。
- 一人称「私」、敖欽に「二番目の兄上」。兄弟へ「〜なりません」「〜しましょう」。
- 根拠：第三回 xy-ch03-013。

1. 敖閏「兄上、あの者と戦ってはなりません。」
2. 敖閏「まず装束をそろえて、帰らせましょう。」
3. 敖閏「私は鎧を一そろい持ってきました。」

### 北海竜王・敖順

- 敖閏の案に賛成し、提供できる品を簡潔に伝える。発言量が少ないので、独自の気弱さや老人語を作らない。
- 一人称「私」、兄弟へ穏やかな「〜ですね」「〜があります」。
- 根拠：第三回 xy-ch03-013。

1. 敖順「そのとおりですね。」
2. 敖順「その案に賛成します。」
3. 敖順「私のところには、雲を歩く靴があります。」

### 魂を取り立てる二人の使者

- 命令書に従って寿命の尽きた者を連行する役人。簡潔に任務を告げる。原文にない悪意や嘲笑は足さない。
- 一人称「我々」、相手に「お前」、「〜した」「〜なのだ」。二人で述べた言葉を掛け合いに分けない。
- 根拠：第三回 xy-ch03-017。

1. 二人の使者「お前のこの世での寿命は尽きた。」
2. 二人の使者「我々は命令を受けて来たのだ。」
3. 二人の使者「お前の魂を連れていく。」

### 冥界の鬼卒たち

- 突然の襲撃に慌てて上へ報告する集団。恐れと切迫を短い言葉で示し、原文にない滑稽な語尾は付けない。
- 王への呼びかけは「大王」、「大変です」「〜てきました」。牛頭・馬面の逃走描写を個別のセリフにしない。
- 根拠：第三回 xy-ch03-017。

1. 鬼卒たち「大王、大変です！」
2. 鬼卒たち「外から何者かが暴れ込んできました！」
3. 鬼卒たち「毛むくじゃらの、雷神のような顔をしております！」

### 冥界の十王

- 王位の威厳より、悟空を恐れて取りなす姿がこの回では前面に出る。名乗りは正式に、弁明や手違いの説明は丁寧にする。
- 一人称「私ども」、悟空へ「上仙」「〜ございます／〜ください」。十王の合同発言を閻羅王一人へ置き換えない。
- 根拠：第三回 xy-ch03-018・019。

1. 十王「上仙、どうかお名前をお聞かせください。」
2. 十王「私どもは、冥界を治める十王でございます。」
3. 十王「どうかお怒りをお鎮めください。使者の手違いではございませんか。」

### 丘弘済真人

- 天上の朝議で来訪者を取り次ぐ、簡潔で改まった奏上。天子への敬意を保ち、必要以上に重い古語を重ねない。
- 呼びかけは「陛下」、「〜が参っております」「〜を待っております」。
- 根拠：第三回 xy-ch03-022。

1. 丘弘済真人「陛下、東海竜王が参っております。」
2. 丘弘済真人「上奏文をお持ちでございます。」
3. 丘弘済真人「お召しのお言葉を、殿外で待っております。」

### 葛仙翁天師

- 冥界からの上奏を取り次ぐ報告者。誰が持参し、誰の文書なのかを明確にする。丘弘済真人と似た格式でも、話者を混同しない。
- 呼びかけは「陛下」、「〜が持参しております」「〜の上奏文でございます」。
- 根拠：第三回 xy-ch03-025。

1. 葛仙翁天師「陛下、冥界の秦広王が参っております。」
2. 葛仙翁天師「地蔵王菩薩の上奏文を持参しております。」
3. 葛仙翁天師「陛下へ差し上げたいとのことでございます。」

### 太白金星（太白長庚星）

- 戦わずに悟空を天界の秩序へ組み込む案を、根拠と利点を挙げて説く調停者。使者としては礼儀正しく、任務を優先して長居しない。
- 一人称「私」、玉帝へ「陛下」「〜と存じます」、悟空へ「大王」「〜ください」。幼児をなだめるような口調にしない。
- 根拠：第三回 xy-ch03-028・029。

1. 太白金星「陛下、まずは天界へお召しになってはいかがでしょう。」
2. 太白金星「大王、私は玉帝の勅命を受けて参りました。」
3. 太白金星「使命がございますので、どうかこのままご同行ください。」

### 地蔵王菩薩（奏状の書き手）

- この回では直接のセリフはなく、奏状に声が現れる。生死の秩序と侵害を論じ、天の軍による鎮圧を請う格式ある文章とする。
- 文書の一人称「拙僧」、「伏してお願い申し上げます」。以下の3例は書き言葉の見本であり、会話の口癖ではない。奏状は人物が音読したセリフへ変えない。
- 根拠：第三回 xy-ch03-025・026。

1. 奏状の文体：「生死の巡りは自然の定めであり、変えることはできません。」
2. 奏状の文体：「拙僧、ここに上奏文を差し上げます。」
3. 奏状の文体：「伏して、冥界の秩序をお守りくださるようお願い申し上げます。」

## 今回の見直しで注意すること

- 第一回の「俺／私」と第二回の「わし／わたし／老孫」の揺れを、相手との関係に基づいて整理する。文字列の一括置換では他人の発言や地の文まで変わるため、セリフごとに確認する。
- 師への「お師匠さま／先生」、表記「お前／おまえ」を統一する。ただし原文の敬意の変化や怒りを削らない。
- 発話導入文と発言者ラベルが重複して読みにくい場合は、怒った・笑った等の意味を残しながら整理する。直接話法でない引用や石碑には人物ラベルを付けない。
- 第二回 xy-ch02-024 の「悟空也現了本相，雜在叢中道」は悟空本人の発言。「我等」という一人称複数だけで集団発言に変えない。続く「大眾道」は弟子たちの発言として区別する。

## 第三回の翻訳で追加する注意

- 第五回は全編、地の文と発言者ラベルを「斉天大聖」で統一する。第四回に正式授与された称号を継承し、逃亡しただけで称号を失ったと補わない。赤脚大仙への変身中も行動主体は「斉天大聖」。会話内の「老孫」「孫大聖」、九曜星官の侮称「弼馬温」、詩の猴王は文脈を保持する。

## 各話初出の読み・難語説明と西遊記辞書

- 各話の本文で初めて出る人物名・地名・固有名詞には、必ず `語（よみ）` の形で読みを付ける。調べても確定しない場合は読みを省略せず、推定を採用し辞書の `reading.status: estimated` と理由を明記する。資料で確認した読みだけを `verified` とする。読みの確度は辞書内で管理し、本文・読書HTMLには「推定」などの確度ラベルを表示しない。
- 姑・舅など現代の一般的な語には、読みも意味説明も付けない。日常の家族呼称・生活語・広く知られた宗教語を機械的に注釈せず、辞書の収録と本文の注釈を分ける。人物名・地名・固有名詞の読みは維持し、古典特有の語義や難解な制度・宗教用語に限って説明を添える。
- 現代日本語で意味の分かりにくい固有名詞・難語は、初出の語直後は `語（よみ）` の読みだけとし、意味説明は各話の `lexicon.first_occurrences` の `gloss_ja` に保存する。読書サイトでは、その本文段落（Segment）の末尾に `語：意味` を初出順に表示する。詩・会話内の改行と発言者ラベルを維持し、章末へまとめない。原訳の自然な説明文は取り除かず、読みだけの初出へ意味を新規追加しない。人物名・地名・称号・物品・概念・難語のすべてに、辞書で読みと意味を記す。
- 初出判定は地の文・台詞・発言者名・詩を含む本文を対象とし、各話の回題・見出しと注本文は除外する。説明の括弧内だけの出現や、長い別名の一部との文字列一致を初出と数えない。
- 同一人物の別名・称号は一つの辞書entryのformsとして対応づけ、各表記について各話の本文で初出を確認する。初出位置は各話の正本YAMLの `lexicon.first_occurrences` に保存し、辞書に保存しない。人物の識別は下の「読者が物語を追える呼称」を優先し、命名以前に後の名を持ち込まない。説明にも後の名前・正体・結末を先取りして書かない。
- 正本は [西遊記辞書](../../lexicons/xiyouji.yaml)、形式・出典・編集手順は [辞書README](../../lexicons/README.md)。西遊記全体を通して使う共通辞書とし、各話の回ID・段落ID・初出位置・本文表示は含めない。収録語は順次整備するが、全語彙を網羅したとはみなさない。
- 本文変更後はその回の `lexicon.first_occurrences`、既存の注参照span、目録、読書サイトを再検証し、本文の初出を人が点検する。辞書検証は `python scripts/validate_xiyouji_lexicon.py`。機械検証だけで語の網羅性・初出判断・読みの正しさを確認済みにしない。

## 読者が物語を追える呼称（第一回〜第三十二回）

- 第一回の石猿→美猴王→孫悟空、第四回の官職・称号の成立は、それぞれ命名・任官の順序どおり保持する。初めから悟空や斉天大聖に置き換えない。
