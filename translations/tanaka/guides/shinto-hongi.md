## 語りの基本

講演を材料にした論説であり、小説として人物の性格・口癖を創作しない。著者の一人称「私」「我々」、読者への「諸君」、問いかけ、反語、自己限定、同じ主張の反復を保つ。「私は信じる」「思われる」「疑問である」「断言できない」を客観的事実へ強めない。本文の基本は読みやすい丁寧語とし、引用は各原文の敬意・態度に合わせる。

政治・宗教・国家・民族・性別・障害・貧困についての価値判断、排斥的表現、帝国主義的主張は、当時の著者や引用者の発言として忠実に訳す。賛同・現代的修正・追加の非難を本文に混ぜない。第115–120コマの乃木将軍の死についての議論は歴史資料の叙述として訳す。著者の評価や動機の推測を訳者の推奨・確認事実へ変えず、原文にない行為の手順・詳細を補わない。

以下の口調例は**すべて創作した語調見本であり、原典の引用や本文に追加する文章ではない**。各分類の例は語尾・距離感の基準であって、個々の引用内容を同一表現へ置換するためのテンプレートではない。

### 1. 著者・田中義能の説明、批評、呼びかけ

根拠：序言6–7、本文10以後全般。自説を丁寧に説明し、強い批判や反語も用いるが、原文にない罵倒・命令を足さない。講演時点の「今日」「今上」は段落ごとに判定する。

- 「私は、この点をもう少し詳しく述べたいと思います。」
- 「しかし、それだけで全体を説明できるでしょうか。」
- 「この点には、十分に注意しなければなりません。」

### 2. 詔勅・神勅の発話主体

根拠：3–5、31–34、64、82–83、94–114。天皇や神の直接の言葉、著者の間接引用、著者による解釈を三層に分ける。「朕」の現代語化では一人称を明示し、臣民への命令・願望の区別を保つ。天照大神、高皇産霊尊、歴代天皇を一人の発言者へ統合しない。

- 「私は、皆がこの教えを守ることを願います。」
- 「臣民は、心を一つにして務めなさい。」
- 「先人の残した事業を失わないようにします。」

### 3. 平田篤胤の引用と本居宣長への敬意・異論

根拠：14–18、51–53、59、61、75、82、93。師を敬う敬語と師説への反対をともに保持する。『入学問答』『霊能真柱』『古道大意』『幽顕辨』『玉襷』等の書名と引用境界を確認。「翁」「先生」の指示対象は隣接文によって確定する。

- 「先生の学問の大きさは、その著作を読めば分かります。」
- 「これは先生の説ですが、私は同意できません。」
- 「道は、実際の事柄の上に備わっているのです。」

### 4. 本居宣長の引用・その説の紹介

根拠：15–18、28、52、58、63、75、89。宣長本人の主張と、田中・篤胤・会沢等による批評を混同しない。反論者に宣長本人の一人称を移さない。

- 「道を学ぶという目的を忘れてはなりません。」
- 「この説を、別の道と取り違えないでください。」
- 「私がここでいう道は、その意味ではありません。」

### 5. 度会延佳と『陽復記衍義』の説明者の説

根拠：22–24、46–48、65、74、92。延佳への紹介と『陽復記衍義』の説明者を別人として扱う。後者はOCRでは「度會〓在」となり、人名の確定は第65コマの画像による。「管見」「左を左、右を右」等の比喩を消さない。

- 「それも道の一部ですが、全部ではありません。」
- 「日常の行いを離れて、別の道があるのではありません。」
- 「そのように呼ぶのは、狭い見方ではないでしょうか。」

### 6. その他の学者・古典・史料の引用群

根拠：16–19、26–28、37、41–55、57–58、65、71–75、80、90、99。荷田春満、賀茂真淵、北畠親房、一条兼良、吉川惟足、山崎闇斎、吉見幸和、村田春海、栗田博士等の説は、同じ引用用の落ち着いた文体でも発話主体を別々に維持する。孔子・孟子・アリストテレス等についても、著者が与える帰属と評価を保持し、一般に知られる原典の文句へ無断で取り替えない。和歌の作者が本文で明示されていなければ補わない。

- 「私の考えは、次のとおりです。」
- 「この点を考えれば、その違いは明らかです。」
- 「その説には、なお疑問が残ります。」

### 7. ダルヴィエルラ伯等の外国人論者

根拠：91–92、118。伯爵名はOCR表記が揺れるため、各出現を原画像で確かめる。引用者の観察・疑問と、著者が外国人一般へ推し広げる推測を分ける。第118コマは引用の終端と著者の再説明に注意。

- 「私は、その点についてたびたび尋ねました。」
- 「しかし、明確な答えは得られませんでした。」
- 「今後どのように進むのか、それが疑問です。」

### 8. 著者が仮定する質問者・反論者・一般人

根拠：20–22、32、47–48、57、60–61、66、73–74、77–78、83–88、95–96、106、113–115。実在人物の直接会話と、著者の想定反論を区別する。「ある人はこう言うでしょう」は仮定のまま残す。名のない質問者に人名を付けない。譬喩の象を触る人々等も別々の説明役を保存。

- 「それは、どういう意味なのでしょうか。」
- 「その説明だけでは、納得できません。」
- 「しかし、別の見方もあるのではありませんか。」

### 9. 逸話・伝承の会話人物

会話は実際の発言単位ごとにラベルを付ける。下記の役割表を用い、原典にない掛け合いや心理を創作しない。原典が間接話法の場合は、無理に直接会話へ変換しない。

| 根拠コマ | 人物・呼称 | 関係・注意 |

| 20 | 国学院大学卒業生、その友人 | 著者への伝聞の中の会話。卒業生と友人は匿名のまま |
| 35 | 最澄の父、最澄、八幡神 | 伝記に記載された言葉と、著者の史料批判を分離 |
| 36–37 | 賀春明神、伝教大師/最澄、神/童子 | 神名・人名は画像照合。伝承を訳者が史実認定しない |
| 47 | 延佳に異論を述べる人、度会延佳 | 討論の質問と回答の主体を逆転しない |

| 80–81 | 皇帝の使者、バヂリウス | 命令・威嚇をする使者と、敬語で返す人物を区別。固有名は画像で照合 |

語調見本（各発話集団につき3個）：

- 逸話の報告者（法師・卒業生など）：「私は、そのように思っていました。」「この前、そう尋ねられました。」「そのため、そこまでで帰りました。」
- 伝承の親・教示者・神：「その恩を忘れてはなりません。」「私に代わって、礼を尽くしてほしい。」「このことを、あなたに伝えます。」
- 名のない問い手・批評者：「それは、どうしてですか。」「その考えには問題がありませんか。」「もう少し説明してください。」
- 皇帝の使者：「その命令に従わなければ、罰を受けるぞ。」「それでも従わないのか。」「そのような答えでは済まない。」
- バヂリウス：「それでも、私の信じるところは変わりません。」「私には、それ以外に持ち物はありません。」「そのことは、承知しています。」
- ルーテル：「私は、それを残念に思っています。」「その理由をお話ししましょう。」「私には、そのように思えるのです。」
- 記事に登場する若者：「私は、困っていました。」「どうすればよいのか、分かりませんでした。」「そのように考えていたのです。」

人物名・呼称表は訳すコマの実画像で追加訂正し、知られている固有名を先回りで入れない。掛け合いでは例として `皇帝の使者「……」`、`バヂリウス「……」` のように各発言の前へ主体を記すが、学説引用を劇の台詞へ変えない。

### 10. 広告の発行者と新聞・雑誌の書評者

根拠：121–129。価格、装丁、頁数、郵税、発行所、住所、振替番号、号数、評者が付す限定や批判まで含める。『時事新報』『大阪毎日新聞』『東京朝日新聞』『読売新聞』『万朝報』『神風』『神社協会雑誌』『青年及青年団』『東京毎日新聞』『二六新報』『報知新聞』『養徳』『東亜之光』『東京日々新聞』『哲学雑誌』『国民新聞』等は出現ごとに題字・号数を画像で確かめ、別媒体を統合しない。匿名書評は媒体名を主体とし、個人評者名を推測しない。

- 広告の声：「本書は、全一冊です。」「定価と郵税は、次のとおりです。」「詳しい内容を、要目に掲げています。」
- 書評の声：「著者の研究には、評価すべき点があります。」「ただし、この点にはなお不満が残ります。」「読者に、一読を勧めたいと思います。」

## この作品で特に照合する事項

1. 「〓」が「教」「清」等に見える箇所でも一括置換しない。教/教学/教育/宗教、清麿等の固有名、否定、数量を画像から個別確定する。
2. 第7・10・26・120・124・128・129コマは読順・表・多段組の重点箇所。柱の「神道本義」、章名、頁番号を本文へ混入させない。目次の頁番号は項目との対応を保持する。
3. 第26コマの「秩序的統一的思想／現世的快活的感情／発展的膨脹的性格」と「神鏡／神璽／神剣」の対応、三要素に教育を加える第68・91コマの論理を崩さない。
4. 神道説の発展を述べる箇所は「着色」「根本」「利用」の区別を保つ。著者は外説の取り込みを認める部分と外教への傾倒を批判する部分を併置している。矛盾に見えるからと編集で均してはならない。
5. 第61等の「明治の大御世」、第67の「今上」と、第108以降の大正期の「今上」は同一の時点ではない。序言が講演材料の重複を認めていることも踏まえ、現代の時制へ自動更新しない。
6. 第75のOCR「大地」、第78の「曹孫」等は誤OCRか原刊表記かを画像で確認する。既完成『神道大意』に同趣旨の箇所があっても、本文・版・細字・註記の同一性を仮定してコピーしない。
7. 国史・西洋史の数値・年代・人物伝の内容が現代の通説と違っても、OCR誤認と原著の説を分ける。訳者判断で訂正した史実を原文へ戻さない。原著自身の疑問・留保（例：最澄/空海の学説創始、家康の遺訓）を維持する。
8. 和歌・漢文の引用は原音仮名の読み替えだけで翻訳完了にせず、引用範囲の意味を現代語にする。原ルビ・送り仮名・返り点・傍点は実際の印刷位置と文字を確認し、理解のため補った全訓と混ぜない。
9. 反復された議論・引用もこの版の本文である。前章との重複を理由に省略しない。改頁をまたぐ文は関係を記録し、原典にない「…」を挿入しない。

## 正本の構造と校訂記録

正本形式はルートの `TRANSLATION_YAML_SPECIFICATION.md` と schema 2.0 を優先する。コマごとの確認記録と正本の検証・全文見直しを区別する。

- 初稿の `translation_status` は `draft`、未確定部分がある場合は `partial` と Issue を使う。独立校閲前に `reviewed` / `ready` へ引き上げない。暫定の `section_id` は `sh-working` を使用可。
- `segments` は意味段落・見出し・表セル等ごと。固定IDは `sh-pNNNN-NNN`（コマ番号4桁、コマ内連番3桁）。既存IDを再割当てしない。原文だけを機械的に頁単位へまとめて長い訳を付けない。
- 画像URL：`https://dl.ndl.go.jp/pid/943392/1/n`。作業時の実画像ファイル、コマ番号、印刷頁、取得方法、画像ハッシュと確認範囲を記録する。通常公式UIから得たPDF/画像を使い、表示が別コマのままなら照合済みにしない。
- 校訂した原文を `source_text`、元OCRを `source_variants` の `kind: ocr` に保持する。座標JSONの対応ID・範囲を `source_alignment` に保持し、校訂根拠・不確実な字は該当箇所の記録へ残す。`source_locations` には画像・コマ等を記録する。
- 原ルビ等は schema の annotation として親字の実出現へ結び付ける。訳注と原注記を区別する。参照や改頁継続は `references` / `groups` を使い、目録・順序・内容ハッシュを統合時に再検証する。
- `source_locations` の `source_id` は `ndl-943392`、`source_sequence` はコマ番号−1、`printed_page` は実画像で確認できた値のみ。`page_record` に柱・欄外・蔵書印等の役割と本文外とする理由、`segment_ids` を記録する。
- 分担はコマ境界を共有するため、前後コマの原文を参照しつつ、自分の担当コマの原文範囲だけを収録する。完了報告は担当範囲と全130コマを区別する。
