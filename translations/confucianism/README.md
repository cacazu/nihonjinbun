# 中国古典 原文・日本語対訳

## 論語

`rongo-zh-ja.yaml` に、漢文原文と日本語新訳を収録しています。通常伝わる全20篇の501章句と、底本にある「知道第二十二」の断片1章句を別立ての付録として収めました。章句の区切り・番号は底本に従います。

- 原著：孔子・弟子たち
- 日本語訳：心霊研究家ポロミン
- 底本：[中国語Wikisource『論語』](https://zh.wikisource.org/wiki/論語)。各篇の固定版URLをYAMLに記載
- 利用条件：日本語訳は[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja)。底本の現代の編集要素も同ライセンスに基づき帰属を表示
- 底本の中国語校注・異文40件は、原文と日本語訳注から区別して保存

発言者や対話の構造を含めて訳しています。解釈の定まらない箇所や、通行本と異なる底本の読みは訳注で示しています。序説は対象外です。
