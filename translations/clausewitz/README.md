# 戦争論 — ドイツ語原文・日本語対訳

原著はカール・フォン・クラウゼヴィッツ『Vom Kriege』（1832–1834年、ベルリン、Ferdinand Dümmler）。前付・全8篇・第3分冊の付録を原著順に訳す。一作品の正本は `vom-kriege-de-ja.yaml` 一つとする。進捗・留保・底本・利用条件はそのYAMLを参照する。

現在は逐次翻訳中で、全篇の完訳・完稿後の全文レビューは未完了。未訳を含む原稿を完成稿として扱わない。再開位置はYAMLの `provenance.progress` に記録する。

本文の主底本は [Bibliotheca Augustana](https://www.tha.de/~harsch/germanica/Chronologie/19Jh/Clausewitz/cla_kri0.html) のドイツ語電子翻刻。初版を掲げるが、現代表記と電子目次の整理があり、初版画像そのものとは区別する。付録・第3分冊前付・電子底本で欠落している原注は、初版1834年に基づくDTAの[TextGrid固定版](https://textgridrep.org/browse/4bjm9.0)を使用する。付録図は[e-raraの初版画像](https://www.e-rara.ch/zut/content/titleinfo/20498226)による。

第7篇末「勝利の頂点について」は、初版では第21章の後に置かれた無番号論文。電子目次の「22」を原著の章番号として補わない。第3分冊編者序文でいう第4巻・第5巻は『遺著集』の刊行順に関する説明であり、『戦争論』第4分冊・第5分冊を意味しない。

## 文体と声の区別

会話を中心とする作品ではない。主な声は著者の理論的な叙述と、編者マリーの序文。引用を通常の会話へ変えず、引用者と引用された文章の著者を区別する。以下の例文は創作の口調見本であり、原典の引用や本文への追加ではない。

| 声 | 根拠 | 方針 | 口調例（3例） |
| --- | --- | --- | --- |
| クラウゼヴィッツ | 著者序文、著者の覚書、第1篇第1章 | 明確な常体。「われわれ」は論述上の著者と読者。仮定・反論・結論を区別し、断定や必然性を勝手に強めない。 | 「まず、この問題を全体との関係で考えよう。」「しかし、現実には別の事情が加わる。」「したがって、この区別を保つ必要がある。」 |
| マリー・フォン・クラウゼヴィッツ | 第1分冊編者序文、第3分冊編者序文 | 丁寧体。一人称は「私」。夫への敬愛と編纂の説明を保ち、著者の理論的断言と混ぜない。 | 「この経緯をお伝えしたいと思います。」「夫は、この仕事に深い愛情を注いでいました。」「ここに、助力くださった方々への感謝を記します。」 |
| リヒテンベルクの引用文 | 著者序文の消防規則の例 | 常体。左右の壁をめぐる冗長な論理を省略せず、原文の滑稽さを残す。引用を実際の対話にしない。 | 「まず、どちらの壁を守るべきか考えなければならない。」「その壁の右には、さらに別の壁がある。」「覚えるには、位置を確かめればよい。」 |

序文中に引用された著者の文章は常体を用いる。マリーの文章中にある夫の短い発言には原文で確かめられる発言者を示す。シャルンホルスト、グナイゼナウ、王族など、言葉を直接引用されていない人物の口調は作らない。

## 呼称と用語

- 著者：カール・フォン・クラウゼヴィッツ。編者：マリー・フォン・クラウゼヴィッツ（旧姓ブリュール伯爵令嬢）。序文の「夫」と著者本文の「われわれ」を混同しない。
- Scharnhorst はシャルンホルスト、Gneisenau はグナイゼナウ、Bonaparte はボナパルト。原文で Napoleon を用いた箇所はナポレオンとする。
- Zweck は文脈に応じて「目的」、Ziel は「目標」。政治上の目的と、戦闘・戦争で達成すべき軍事上の目標を区別する。
- Strategie は「戦略」、Taktik は「戦術」、Gefecht は「戦闘」、Schlacht は「会戦」。Streitkräfte は「戦力」または実体としての「軍隊」。
- moralisch は精神・士気に関する文脈では「精神的」とし、道徳的な善悪に読み替えない。Friktion は「摩擦」、Schwerpunkt は「重心」。
- Niederwerfung は「打倒」、Vernichtung は文脈に応じて「撃滅」「破壊」。敵の戦力を無力化する議論を、原文にない住民の殺害へ拡張しない。

## 原文と進捗の保持

固定ID・原文・原著順を保持する。電子翻刻の空白整理や綴り、初版画像から補った部分はYAMLの出典・来歴に記録する。本文・原注・編者注・訳注を区別し、翻刻にない付録を対象外へ変更しない。逐次翻訳中の確認と、完稿後の全文対照・独立レビューを別々に記録する。
