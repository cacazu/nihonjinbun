# 『日本精神と国体の本質』翻訳作業ガイド

## 語り手
田中義能の神職会における講演。聴衆への丁寧な「です・ます」、一人称「私」「私たち」、呼びかけ「皆さん」。敬神・皇室敬語は原文の敬意を保持する。反復、具体例、問いかけを省略しない。歴史的な国家・民族論は講演者の主張として翻訳し、現代の事実として訂正・補強しない。差別的・同化主義的な語も無断削除しない。
創作の口調例（本文へ追加しない）：①「まず、この点をお話ししたいと思います。」②「皆さんもご承知のとおりです。」③「私たちは、この意味を十分に考えなければなりません。」
## 引用中の話者
神勅・詔勅・御製は原典の引用として区別し、意味の通る現代語にする。引用文を講演者自身の発言に変えない。
創作口調例（原典引用ではない）：①「この国を治めなさい。」②「その心を失ってはならない。」③「末永く栄えるように。」
講演内の対話（矢田とアメリカ人等）は各発言に話者名を付け、質問・返答の順序を保持する。名前不明の米国人は「アメリカ人の友人」とする。
創作口調例（原典引用ではない）：①友人「あなたの国で大切なことは何ですか。」②矢田「私には分かりません。」③友人「ほかにもあるのではありませんか。」
