# 皇国伝統の精神（田中義能、1936）翻訳方針

NDL PID 1092188。原資料の全文OCRを先に保存し、全26コマの画像で本文・前後付・奥付を照合する。原文の政治的・宗教的主張は著者の歴史的主張として忠実に訳し、現代的事実認定や賛同に置き換えない。要約・省略・根拠のない補完はしない。

## 語り分け
### 著者の説明・講演
一人称は原文に従い「私」「私たち」。断定・留保・呼び掛けの強さを保つ。原文の講演調を読みやすい現代日本語にし、原文にない対話を作らない。
例（口調の試作、原文の引用ではない）：
- 私は、この点をまず明らかにしておきたいと思います。
- そこで、次にその意味を考えてみましょう。
- こうした考え方が、ここで述べる精神なのです。
### 古典・詔勅等の引用
引用の境界と発話主体を明示し、権威的表現を著者自身の言葉に混ぜない。原文をsource_textに保存し、現代語訳を対応させる。
例（口調の試作）：
- ここに、その務めを果たすように。
- その徳を受け継ぎ、後の世に伝える。
- 国を治め、民を安んじる。
### 出版者・奥付
書誌情報・価格・住所・広告の別を保ち、講演本文と混同しない。
例（口調の試作）：
- 昭和11年発行。
- 著者：田中義能。
- 発行所：新更会刊行部。

## 構造と検証
コマ順を保ち、柱・ノンブル・蔵書印・無文字部分は除外理由を記録する。ページをまたぐ文を取り落とさず、OCRの行順と原画像を照合する。OCR訂正は元表記・訂正・理由を記録し、原刷の誤字と区別する。画像未確認・判読不明は正直に記録する。YAMLはschema_version 2.0を使用し、独立レビュー前に完成と記さない。

## 成果物と再現
- `fulltext-original.zip`：書籍ページの実在する全文リンクから取得した未改変OCR。
- `raw/`：ZIP内の全文・各コマTXT/座標JSON。正規配置時は `sources/ndl-1092188/ocr/`。
- `images/`・`manifest.json`・`image-manifest.json`：原画像全26コマと取得証跡。
- `acquisition.json`：全文リンク・書誌・画像/生OCRのSHA256。
- `build_draft.py` → `draft.json`：画像対照原文と全文現代語訳。
- `finalize.py`（`ruby_more.py`・`kunten.py`を使用）→ `kokoku-dento-no-seishin-ja.yaml` / `draft-enriched.json`：原ルビ、訓点、訳注、章構造・改頁継続を追加。
- `check.py` → `validation.json`：JSON Schema、全注記の文字位置、26コマの対応を検証。

訓点付き漢文は `source_variants.kind: diplomatic` に保存する。小書き仮名は `〔 〕`、返り点は `㆑` 等で表し、字の大小と縦書き配置は原画像を参照する。原典内の異表記（道實、磐は座、正道正直）をOCR誤認と混同せず、原字を保ったうえで訳注で説明する。

ユーザー指定順序は、対象一覧→全文翻訳→YAML→独立見直し→原稿プッシュ→GitHub Pages HTML→見直し→別プッシュ。原稿の独立レビュー完了前には公開準備済みとしない。
