# 『日本書紀概説』原資料・校閲記録

- 底本：田中義能著、日本学術研究会、1938年、NDL 1048202。全128コマ。別版は含めない。
- `fulltext.zip`：資料ページの全文テキストデータを未改変で保存したもの。全128コマのTXTと座標JSON（計256ファイル）を含む。完成原稿のOCR原形と各参照IDはこのZIP内のJSON名・IDに対応する。頁全体の対応を、精密な行・段落対応とは扱わない。
- `manifest.json`：NDLの資料情報・画像位置・権利表示の取得記録。
- `reacquired-image-records.json`：取得した原画像1–120コマのSHA-256等。後続の取得失敗記録は画像照合済みの根拠とはしない。
- `ui-evidence/`：121–128コマを通常公開閲覧画面で表示し、拡大・パンして保存した54枚とmanifest。実エンコードはJPEGであり、API原画像や無損失PNGではない。本文のない整理票・撮影終了札も位置確認のため保存した。
- `completed-manuscript-review.json`：全1144対訳単位の完稿後全文実読と修正差分再読、範囲別原画像校閲、最終内容hash・局所留保の記録。各段階を混同せず、局所不鮮明字を推定確定していない。

原刊の歴史的・宗教的・政治的主張や引用広告の評価は、原著・各引用者の見解として保持する。原著の異説を現代の通説へ無断で置き換えた版ではない。
