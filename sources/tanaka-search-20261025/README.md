# 田中義能：指定検索結果の対象一覧

2026年10月25日確認。[指定検索](https://lab.ndl.go.jp/dl/fulltext?from=0&keyword=%E7%94%B0%E4%B8%AD%E7%BE%A9%E8%83%BD&f-responsibility=%E7%94%B0%E4%B8%AD%E7%BE%A9%E8%83%BD)の1頁目20件、2頁目（from=20）3件、計23件。表示中の検索結果から取得した書名・資料ID・書誌文字列をDOM記録に保存した。

同一作品の別版をまとめると17作品。既訳3作品（神道大意、神道哲学精義、本居宣長の哲学）は収録範囲と未訳単位を確認し除外した。残る14作品を新規対象とする。最新の「別版はいらない」という指示に従い、各作品1版のみを選定し、既訳作品の別版比較も行わない。採用候補・除外資料は inventory.json に記録した。selected_pending は翻訳完了を意味しない。

作業順は、リストアップ→全文OCR取得・原画像照合と翻訳→YAML→見直し→原稿プッシュ→GitHub Pages用HTML→見直し→HTMLプッシュ。既存の訳文と無関係な作品を変更しない。各原稿の実際の進捗は正本YAMLのworkflowと個別取得記録を参照する。
