# 神道史綱要（1915、NDL 943545）現代語訳方針

本書は田中義能の神道史論。実資料の全文配布ZIPを先に取得し、全45コマの原画像を照合してから原文・訳文を記録する。表紙題簽、序、本文、奥付、広告を区別し、整理番号・蔵書印・柱・頁番号・撮影札は本文外の頁記録へ残す。別版は対象外。

## 著者・引用・広告の声
- 著者の叙述は「私たち」など原文の主体を維持した常体の論説。断定・推量・批判・留保を変えず、政治的宗教的価値判断を現代の事実認定へ強めない。
  - 創作の口調見本（本文には加えない）：「ここに、その変遷を述べよう。」「この点から、本質を知ることができる。」「しかし、それが実際にそうであったかは疑問である。」
- 引用は引用主体を保持。漢文・宣命は現代日本語へ全訳し、神道・仏教術語を消さない。文献引用を会話化しない。
  - 創作の口調見本：「私はこの教えを守る。」「神々の道も、これに背くことはない。」「この名は、その理を表すのである。」
- 出版広告・書評は著者本文から区別し、題名・価格・推薦者・住所等を省略しない。
  - 創作の口調見本：「本書はその学説を述べる。」「定価は三十銭。」「読者の参考となる一冊である。」

## 呼称と校訂
田中義能を著者として扱い、引用の「我」を著者へ移さない。神名・人名（天御中主神、高皇産霊神、神皇産霊神、天照大神、平田篤胤、最澄、空海等）は画像の原字を source_text に保ち、訳文では通用字体を基本とする。OCRの〓を機械的に同じ字へ置換しない。割注・ルビ・傍注・改頁継続を本文順へ復元し、原注と訳注を分ける。原典の疑わしい表記は画像に一致させ、推測修正ではなく留保を付ける。
